# Records and me

Use the no-parameter root calls shown by
[`examples/sync_records_and_me.py`](../../examples/sync_records_and_me.py) and
[`examples/async_records_and_me.py`](../../examples/async_records_and_me.py). Records are one
unpaged collection. Spend and remaining values from `me()` are estimates, not an exact balance,
quota, or available funds. Treat received values as data. See the
[API reference](../api/README.md).
